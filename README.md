# Texas2000 — סורקים, משלמים, הולכים

מערכת למסעדות ובתי קפה: הסועד סורק את הברקוד שעל השולחן, רואה את החשבון, משלם (כולו או חלק ממנו) ומשאיר טיפ. לא צריך לחכות למלצר ולא צריך להוריד אפליקציה: זה עמוד אינטרנט שנפתח מהמצלמה של הטלפון.

## מה יש בגרסה הזו (MVP)

**מסך לקוח** (`/pay.html?t=<קוד שולחן>`, נפתח מהברקוד)
- פירוט החשבון של השולחן
- תשלום על כל היתרה, חלוקה שווה בין סועדים או סכום חופשי
- טיפ: בלי / 10% / 12% / 15% / סכום אחר
- Apple Pay, Google Pay, bit, כרטיס אשראי
- כמה סועדים יכולים לשלם במקביל: היתרה מתעדכנת אוטומטית, ואי אפשר לשלם יותר ממה שנשאר

**מסך צוות** (`/admin.html`, בכניסה עם PIN)
- רשימת שולחנות עם ברקוד לכל שולחן, ואפשרות להדפיס את כל הברקודים
- פתיחת חשבון, הוספה והסרה של פריטים
- רואים בזמן אמת מי שילם, כמה ובאיזה אמצעי, וכמה טיפ נאסף
- שחרור שולחן אחרי תשלום, או סגירה ידנית (למשל אחרי תשלום במזומן)

## הרצה

```bash
npm install
npm start        # http://localhost:3000 — PIN ברירת מחדל: 1234
npm test
```

משתני סביבה: `PORT`, `ADMIN_PIN`, `DB_FILE`, `PUBLIC_URL` (הכתובת הציבורית שתוטבע בברקודים).
דרוש Node 22.13 ומעלה (משתמש ב-SQLite המובנה).

## מה חסר כדי לצאת לשוק

1. **סליקה אמיתית**: כרגע `src/payments.js` מדמה את התשלום. צריך לחבר ספק סליקה ישראלי (Tranzila, CardCom, Grow/Meshulam, PayPlus) דרך דף תשלום מאובטח שלהם, כך שמספרי כרטיסים לא עוברים אצלנו.
2. **חיבור לקופה (POS)**: היום הצוות מקליד פריטים ידנית. במסעדה אמיתית החשבון צריך להגיע אוטומטית ממערכת הקופה (למשל Tabit, Beecomm) ולחזור אליה כשהוא שולם.
3. **ריבוי מסעדות**: הרשמה, משתמש לכל מסעדה, דוחות ועמלות.
4. **חשבונית / קבלה דיגיטלית** לפי דרישות רשות המסים.
5. **חלוקת טיפים** לפי משמרת או מלצר.
6. **בחירת פריטים**: כל סועד משלם רק על מה שהזמין.
